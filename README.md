# variant-normalization-go

VCF 文本变异记录的规范化、多等位拆分、跨来源去重合并与磁盘持久化查询服务。
纯 Go 标准库实现，无第三方依赖。

## 能力概览

1. **变异规范化**：等位基因修剪（parsimony）与左对齐（left alignment），同一变异的任意等价写法归一到唯一表示；格式非法与坐标越界分别以 `invalid_format`、`out_of_range` 拒绝。
2. **多等位拆分**：一条多 ALT 记录拆为多条双等位记录；基因型与 FORMAT 字段（`Number=R/A/G`）按拆分关系重映射，信息与基因型语义保持一致。
3. **跨来源去重与合并**：规范表示相同只留一条；同 `chrom:pos:ref` 不同 ALT 合并为多 ALT 记录；结果与到达顺序无关，全部来源保留可追溯。
4. **注释/统计重算**：合并后重算 `AC/AF/AN/NS`，QUAL 取最大，FILTER 取并集并应用质量阈值，不保留与结果矛盾的历史值。
5. **区间查询**：按染色体与位置区间查询，全局稳定排序（染色体→坐标→REF→ALT）与基于游标的稳定翻页；快照隔离保证查询看不到未完成的合并中间态。
6. **流式导入与断点恢复**：固定条数的内存缓冲刷成有序段，内存占用不随输入总量线性增长；检查点持久化字节偏移，崩溃后从最近刷盘点继续，不重复不遗漏。
7. **来源优先级与过滤阈值**：合并保留策略由配置决定；配置随导入版本持久化，变更只影响后续导入，历史记录保持自洽。
8. **自动化测试**：覆盖规范化、拆分、去重合并、乱序到达、中断恢复与并发查询。

## 规范化规则

- 仅支持显式序列的 SNP / MNP / indel；符号等位（`<DEL>`、断裂端 `[`/`]`、`*`）拒绝为 `invalid_format`。
- 等位基因只接受 `A/C/G/T/N`（大小写不敏感）；染色体缺失、`POS<1`、REF/ALT 缺失拒绝。
- 提供参考序列时校验：染色体未知或记录超出 contig 长度 → `out_of_range`；REF 与参考不一致 → `invalid_format`。
- 规范化采用标准迭代过程（vt / bcftools norm 等价）：
  1. 去除 REF 与 ALT 的共同后缀（每条至少保留 1 个锚定碱基）；
  2. 首碱基相同时向上游扩展窗口并再次去共同后缀，直到首碱基不同或到达染色体起点；
  3. 去除共同前缀，POS 相应右移。
  结果是最左、最短表示，对同一变异的任意等价写法唯一。
- 多等位记录先拆分（见下），再对每个 ALT 独立规范化。

## 多等位拆分与基因型重映射

- 每个 ALT 生成一条双等位记录；基因型把目标 ALT 映射为 `1`，其它非 REF 等位映射为缺失 `.`，相位（`/` vs `|`）保留。
- FORMAT 字段按头部 `Number` 重映射：
  - `R`（ref+每ALT，如 AD）：保留 `REF` 与目标 ALT；
  - `A`（每ALT）：保留目标 ALT；
  - `G`（基因型组合）：按 VCF 的 `00,01,11,02,12,22...` 顺序取 `0/0、0/t、t/t`；
  - 标量（`1` 等）原样保留。

## 合并策略

- 分组键：`chrom:pos:ref`（规范坐标与参考等位）。
- 相同规范 ALT 去重；不同 ALT 合并为一条记录，ALT 按字典序升序，因此结果确定且与到达顺序无关。
- **基底记录**：来源优先级数值最小者；平手取来源 ID 字典序最小，再平手按坐标/ALT。
- 样本按样本名跨来源合并（高优先级来源先到者保留），基因型重映射到统一 ALT 索引；`FORMAT` 以 `GT` 优先、其余字典序排列。
- `ID`、`FILTER` 取跨来源并集；`QUAL` 取最大值；非派生 `INFO` 字段保留（基底优先），`AC/AF/AN/NS` 一律删除后按合并结果重算。
- 合并结果 `QUAL < min_qual` 时 FILTER 加 `LowQual`；无任何过滤器时为 `PASS`。
- 所有来源的 `(source, line, id)` 全量保留并按来源/行号排序，可追溯每条记录的出处。

## 配置项

见 `config.example.json`：

| 字段 | 含义 |
| --- | --- |
| `source_priority` | 来源 ID → 优先级，数值越小越优先 |
| `default_priority` | 未列出来源的默认优先级 |
| `min_qual` | 质量阈值，低于则 FILTER 标记 `LowQual` |
| `config_version` | 配置版本，随每次导入的记录持久化 |

配置在导入开始时读取并写入该批次结果；之后修改配置不回溯改写已入库记录。

## 存储与并发

- 每个已提交版本由若干按 Key 排序的 gob 段文件组成，`manifest.json` 原子指向当前版本。
- 导入在新段上进行，跨来源合并在提交点一次性完成，再原子切换清单；查询持有某一版本的只读快照（每次查询独立打开段文件），写入与查询并发时绝不暴露中间态。
- 排序键中的坐标零填充定宽，字符串字典序与数值序一致，翻页游标即上一页最后一条记录的 Key。

## 命令行

```sh
# 导入（input 为 - 时从 stdin 读取并缓冲到临时文件）
varnorm import <store-dir> <source-id> <input.vcf[.gz]|-> \
  [--ref genome.fa] [--config config.json] [--flush 10000]

# 区间查询与翻页
varnorm query <store-dir> --chrom chr1 [--start N] [--end N] \
  [--limit N] [--after '<cursor>']
```

导入会自动识别明文/gzip VCF，崩溃后对同一来源再次执行 `import` 即从最近检查点继续。
